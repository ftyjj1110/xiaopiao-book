购物小票管家 V2（OCR识别改进测试版）

使用：
1. 将 index.html 上传到你自己的 receipt-keeper 仓库，替换原来的 index.html。
2. 用 GitHub Pages 发布后，使用 https 网页地址打开，不要直接用手机文件预览打开。
3. 添加小票，拍照或从相册选择照片，点击“自动识别小票”。
4. 核对商店、日期、商品名称、每件商品金额和小票总价后保存。

说明：
- OCR 需要网络加载识别组件和中文/英文识别数据。
- 本版本针对山姆、开市客常见票面做了识别规则调整，并增加图片放大、灰度和对比度增强。
- OCR 会受照片倾斜、反光、遮挡、模糊和票面排版影响。识别结果请核对；不确定的内容不会保证自动识别正确。
- 数据保存在当前浏览器本地。更换设备或清理浏览器数据前，请先在“设置”中导出 JSON 备份。
- 这是在原购物小票管家代码上更新 OCR 的测试版；不要上传到宝贝课程管家仓库。
